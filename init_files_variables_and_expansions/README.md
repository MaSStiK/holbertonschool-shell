# holbertonschool-shell/init_files_variables_and_expansions

## Files

- `0-alias` - Create an alias for ls that deletes all non-hidden files in the current directory.
- `1-hello_you` - Print a greeting with the current user's name.
- `2-path` - Add `/action` to the end of the PATH variable.
- `3-paths` - Count the directories in the PATH variable.
- `4-global_variables` - List all environment variables.
- `5-local_variables` - List all shell variables and functions.
- `6-create_local_variable` - Create a local variable named BEST.
- `7-create_global_variable` - Create a global variable named BEST.
- `8-true_knowledge` - Add 128 to the TRUEKNOWLEDGE variable.
- `9-divide_and_rule` - Divide POWER by DIVIDE.
- `10-love_exponent_breath` - Raise BREATH to the power of LOVE.
- `11-binary_to_decimal` - Convert a binary number to decimal.
- `12-combinations` - Print all two-letter combinations except `oo`.
- `13-print_float` - Print a number with two decimal places.
- `14-decimal_to_hexadecimal` - Convert a decimal number to hexadecimal.
- `15-rot13` - Encode and decode text using ROT13 encryption.
- `16-odd` - Print every other line from the input, starting with the first.
- `17-water_and_stir` - Add two numbers in custom bases and convert the result to another base.
