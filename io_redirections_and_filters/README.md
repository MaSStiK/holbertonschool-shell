# holbertonschool-shell/io_redirections_and_filters

## Files

- `0-hello_world` - Print "Hello, World" followed by a new line.
- `1-confused_smiley` - Display a confused smiley.
- `2-hellofile` - Display the contents of `/etc/passwd`.
- `3-twofiles` - Display the contents of `/etc/passwd` and `/etc/hosts`.
- `4-lastlines` - Display the last 10 lines of a file.
- `5-firstlines` - Display the first 10 lines of a file.
- `6-third_line` - Display the third line of a file.
- `7-file` - Create a file with a special name and text content.
- `8-cwd_state` - Save the current directory listing to a file.
- `9-duplicate_last_line` - Duplicate the last line of a file.
- `10-no_more_js` - Delete all `.js` files recursively.
- `11-directories` - Count all directories and subdirectories.
- `12-newest_files` - Display the 10 newest files.
- `13-unique` - Display sorted words that appear exactly once.
- `14-findthatword` - Display lines containing `root`.
- `15-countthatword` - Count lines containing `bin`.
- `16-whatsnext` - Display lines containing `root` and 3 lines after each match.
- `17-hidethisword` - Display lines that do not contain `bin`.
- `18-letteronly` - Display lines starting with a letter.
- `19-AZ` - Replace `A` with `Z` and `c` with `e`.
- `20-hiago` - Remove all `C` and `c` characters.
- `21-reverse` - Reverse the input text.
- `22-users_and_homes` - Display users and their home directories, sorted by username.
- `23-empty_casks` - Find empty files and directories recursively, displaying only their names.
