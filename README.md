# holbertonschool-shell

A repository for learning Linux, Shell scripting, and basic terminal commands.

## Project Structure

```text
holbertonschool-shell/
├── basics/
├── init_files_variables_and_expansions/
├── io_redirections_and_filters/
├── permissions/
└── README.md
```

## Directories

- **`basics/`** - Basic Shell commands, directory navigation, file management, and symbolic links.
- **`init_files_variables_and_expansions/`** - Shell initialization files, variables, environment variables, aliases, and expansions.
- **`io_redirections_and_filters/`** - Input/output redirections, pipes, text processing, filtering, and file manipulation.
- **`permissions/`** - File permissions, ownership, user groups, and access control.

Each directory contains Shell scripts for Holberton School tasks and its own `README.md` with descriptions of the files.
